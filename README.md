## 🎮 Overview

**OVERCLOCKED: Silicon Tether** is a high-speed arcade twin-node defense game built with pure vanilla HTML5, CSS3, Canvas2D, and the Web Audio API.

When malware infiltrates through the physical USB mouse port after downloading a bogus "free FPS booster", the player commands the motherboard's emergency sub-routine: a high-voltage plasma tether that fights inward through the hardware buses toward the CPU.

## 🕹️ Controls

| Key / Action | Function |
| :--- | :--- |
| **`[WASD]` / Arrow Keys** | Pilot Node A (Inertial Ship Movement) |
| **`[Mouse]`** | Aim Node B (Targeting Reticle, max 380px radius) |
| **`[Space]` / `[LMB]`** | **Active High-Voltage Surge** (Required to slice enemies) |
| **`[Q]`** | **EMP Discharge** (240px bullet deflection & 2s stun) |
| **`[E]`** | **Cryo Nova** (170px blizzard at reticle, freezes enemies & cools -20°C) |
| **`[Shift]` / `[R]`** | **Hyper-Drift** (Instant supersonic reel dash + cut) |
| **Hover in Cryo Bay (2.5s)** | Cools all heat back to 40.0°C nominal & restores +15% Core HP |
| **`[M]`** | Toggle Procedural Web Audio |

## ⚡ The Thermal Economy

* **Nominal Range (40.0°C – 69.9°C):** 3.80 GHz baseline, standard score multiplier.
* **Overclock Zone (70.0°C – 99.9°C):** Ramps up to **6.50 GHz**, grants **5X score multiplier**, triggers hardware bullet-time slow-mo, and deflects bullets into dual homing lasers!
* **Thermal Lockdown (100.0°C):** Overheats for 2.5 seconds (weapons locked, alarms trigger, forced cooling).

## 🧩 4 Hardware Stages

1. **Stage 1: USB 3.2 Host Controller (Mouse Buffer)** - Matrix Green (`#00ff88`), 3 waves.
2. **Stage 2: System RAM (DDR5 Dual-Channel Matrix)** - Electric Cyan (`#00f0ff`), dual DIMMs with gold pins, 3 waves.
3. **Stage 3: Graphics Processor (RTX VRAM & Shader Die)** - Magenta (`#d946ef`), twin-axial counter-spinning fans, 4 waves.
4. **Stage 4: Central Processing Unit (CPU V-Core Matrix)** - ROG Crimson (`#ff003c`), LGA socket with real-time temperature, 5 waves.
